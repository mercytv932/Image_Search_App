Image Search App

A responsive web application that allows users to search and discover high-quality images in real time using an external image API.

Features
Search for images by keyword
Display image results in a responsive grid layout
View image previews instantly
Load multiple image results
Error handling for invalid searches
Loading state while fetching data
Mobile-friendly design
